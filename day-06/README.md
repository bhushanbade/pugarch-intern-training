# Day 6 — TypeScript + React

## Overview

Day 6 focuses on learning TypeScript and using it with React to build a component-based Employee Management Dashboard.

The Day 5 JavaScript Employee Dashboard was converted into a TypeScript + React application with reusable components, API integration and employee management features.

---

## Objectives

- Learn TypeScript fundamentals.
- Understand interfaces, type aliases and union types.
- Learn type-safe functions and objects.
- Understand generics, type narrowing and type guards.
- Learn React components and JSX.
- Understand props, state and events.
- Use `useState` and `useEffect`.
- Work with forms and API calls.
- Build reusable React components.
- Build an Employee Management Dashboard.
