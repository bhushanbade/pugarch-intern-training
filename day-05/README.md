# Day 5 — JavaScript & Employee Dashboard

## Objective

The objective of Day 5 was to learn modern JavaScript concepts, asynchronous programming, APIs, and apply them by building a simple Employee Dashboard using Vanilla JavaScript.

The task was completed without using unnecessary external libraries.

---

## Topics Covered

### JavaScript Fundamentals

- `let` and `const`
- Data types
- Functions
- Arrow functions
- Arrays
- Objects
- Template literals
- Destructuring
- Spread operator
- Rest operator

### Array Methods

The following JavaScript array methods were practiced:

- `map()`
- `filter()`
- `reduce()`
- `find()`
- `some()`
- `every()`
- `sort()`

### Advanced JavaScript

Basic implementations and examples were created for:

- Scope
- Closures
- Callbacks
- Promises
- `async/await`
- Error handling
- Modules

### APIs and Asynchronous Programming

The following concepts were practiced:

- HTTP request concepts
- JSON
- Fetch API
- Asynchronous programming
- REST API concepts
- GET request
- Error handling using `try...catch`

---

# Employee Dashboard

As the practical assignment, a simple Employee Dashboard was developed using:

- HTML
- CSS
- Vanilla JavaScript
- JSON data
- Fetch API

The dashboard loads employee data from a JSON file and provides basic employee management operations.

---

## Dashboard Features

### 1. Employee Listing

Displays all available employees with their:

- Name
- Department
- Salary
- Email

### 2. Search

Employees can be searched by name.

### 3. Filter

Employees can be filtered based on department.

Available departments include:

- IT
- HR
- Finance

### 4. Sort

Employees can be sorted according to salary.

### 5. View Employee

The View option displays the selected employee's details.

### 6. Add Employee

A new employee can be added using the dashboard.

### 7. Edit Employee

An employee's salary can be updated.

### 8. Delete Employee

An employee can be removed from the dashboard.
