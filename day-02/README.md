# Day 2 — Python Fundamentals & Management System

## Objective

Learn Python fundamentals, file handling, exception handling,
and basic OOP concepts while building a CLI management system.

## Technology

- Python
- JSON
- CSV
- Git
- GitHub

## Python Exercises

Covered:

- Variables and data types
- Lists
- Tuples
- Sets
- Dictionaries
- Conditions
- Loops
- Functions
- Lambda
- List comprehensions
- Exception handling
- File handling
- JSON

## Management System

Features:

- Add Employee
- Update Employee
- Delete Employee
- Search Employee
- List Employees
- Filter by Department
- Sort Employees
- Employee Statistics
- JSON data persistence

## CSV Analysis

The CSV analysis program:

- Reads employee data
- Calculates total employees
- Calculates average salary
- Finds highest salary employee
- Filters employees by department

## How to Run

### Management System

cd management-system
python app.py
