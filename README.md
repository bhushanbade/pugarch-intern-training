# PugArch Internship Training

A 10-Day technical training project completed as part of the **PugArch Technology Internship Program**.

## Overview

This repository contains the practical work completed from **Day 1 to Day 10**, covering data analysis, Python, machine learning, JavaScript, APIs, frontend development, backend development, and full-stack application development.

## Day-wise Work

| Day | Work |
|-----|------|
| Day 1 | Project setup, GitHub workflow and basic tasks |
| Day 2 | Dataset analysis and exploration |
| Day 3 | Data cleaning and preprocessing |
| Day 4 | Machine Learning fundamentals and implementation |
| Day 5 | JavaScript fundamentals, arrays, APIs and dashboard |
| Day 6 | Frontend development and API integration |
| Day 7 | Backend and REST API development |
| Day 8 | Laravel API, MySQL database and CRUD operations |
| Day 9 | Full-stack integration and application development |
| Day 10 | Final Smart Facility Management System |

## Final Project — FacilityOps

**FacilityOps** is a full-stack Smart Facility Management System designed to manage facility operations from a centralized dashboard.

### Key Features

- Dashboard with operational metrics
- Facility management
- Inspection management
- Complaint tracking
- Employee management
- Facility performance
- Search, filtering and sorting
- REST API integration
- MySQL database
- Angular inspection module
- Responsive professional UI

## Mini Projects & Practical Work

Along with the final project, the training included several hands-on applications:

- **Programming Challenge** — Problem-solving and programming fundamentals
- **Python Application** — Python fundamentals, OOP and file handling
- **Data Analysis Project** — Data cleaning, analysis and visualization using Python
- **ML Prediction Project** — Machine learning model development and evaluation
- **JavaScript Employee Dashboard** — JavaScript application using API/JSON data
- **React Application** — React and TypeScript-based frontend application
- **Full-Stack Application** — Frontend, backend and REST API integration
- **Laravel CRUD API** — Database-driven REST API with MySQL
- **Angular Application** — Angular application with services and API integration
- **FacilityOps** — Final full-stack Smart Facility Management System

## Technologies & Tools

- **Programming:** Python, JavaScript, TypeScript
- **Data & AI/ML:** NumPy, Pandas, Matplotlib, Scikit-learn
- **Frontend:** React, Angular
- **Backend:** Node.js, Express.js, Laravel
- **Database:** MySQL, SQL
- **APIs:** REST APIs, API Integration
- **Tools:** Git, GitHub, VS Code, Postman
