# Day 3 — Data Analysis with NumPy and Pandas

## Objective

Learn basic data analysis using Python, NumPy, Pandas and
Matplotlib and apply the concepts to a sample facility dataset.

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib

## Work Completed

### NumPy

- Created arrays
- Performed indexing and slicing
- Performed mathematical operations
- Calculated mean, minimum and maximum

### Pandas

- Created DataFrames
- Loaded CSV data
- Checked missing values
- Checked duplicates
- Cleaned numeric columns
- Filtered records
- Grouped data
- Calculated statistics

### Visualization

Created:

- Cleanliness score chart
- Complaints chart
- Footfall vs cleanliness scatter plot

## Dataset

A sample facility dataset was created for practicing
data cleaning and analysis.

## Risk Analysis

A simple rule-based risk score was created using:

- Cleanliness score
- Odor score
- Waste level
- Complaints
- Hours since cleaning

The scoring approach was used as a beginner-level attempt
to understand how facility risk could be represented.
